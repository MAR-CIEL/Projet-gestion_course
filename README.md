# Projet BTS 2 CIEL option Informatique et Réseaux (E6) : COVACIEL 2026 (voir informations sur internet) - Partie Gestion de course
## Mon rôle dans le projet : 
 * Développement du module de réception, gestion et affichage des données télémétriques (suivi des performances - vitesse, batterie, distance parcourue...) en temps réel des voitures
 * Développement du module de réception et affichage du flux vidéo en temps réel de chaque voiture
 * Développement d'un dashboard web pour les équipes, pour qu'elles suivent en détail les performances et le flux vidéo en temps réel de leur voiture (un dashboard adapté par équipe) - Composé également du chronométrage et du classement de la course en temps réel

### Cette branche est dédiée à mon rôle, chaque collaborateur ayant son rôle et donc sa branche dans le repo. Elle contient les codes sources pour un modèle du dashboard partielle final, et les codes sources d'une version similaire, mais avec une simulation complète. Le dashboard final est partielle car il ne contient pas l'implémentation du chronométrage, tracking et classement en temps réel, du fait que je ne couvre pas ces tâches dans mon rôle. Cette solution prend donc seulement en compte la télémétrie et le flux vidéo, avec un rendu UX complet et responsive. Chaque solution postée ici se fait avec des réseaux personnalisés. Beaucoup de configuration à faire pour le déploiement.
